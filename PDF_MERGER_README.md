# PDF Merger - Программа для объединения PDF файлов

Desktop приложение с графическим интерфейсом для объединения нескольких PDF файлов в один.

## Возможности

- ✅ Простой и понятный графический интерфейс
- ✅ Добавление множественных PDF файлов
- ✅ Изменение порядка файлов (перемещение вверх/вниз)
- ✅ Удаление отдельных файлов из списка
- ✅ Быстрое объединение всех файлов в один PDF
- ✅ Автоматическое открытие папки с результатом

## Установка

### 1. Установите зависимости

```bash
pip install PyPDF2
```

Или установите все зависимости проекта:

```bash
pip install -r requirements.txt
```

### 2. Убедитесь, что у вас установлен Python 3.8+

```bash
python --version
```

## Запуск программы

```bash
python pdf_merger.py
```

Или сделайте файл исполняемым (Linux/Mac):

```bash
chmod +x pdf_merger.py
./pdf_merger.py
```

## Использование

1. **Добавьте PDF файлы**
   - Нажмите кнопку "➕ Добавить PDF файлы"
   - Выберите один или несколько PDF файлов
   - Файлы появятся в списке

2. **Измените порядок (по желанию)**
   - Выберите файл в списке
   - Используйте кнопки "⬆️ Вверх" или "⬇️ Вниз" для изменения порядка
   - Файлы будут объединены в том порядке, в котором они показаны в списке

3. **Удалите ненужные файлы (по желанию)**
   - Выберите файл в списке
   - Нажмите "❌ Удалить выбранный" для удаления одного файла
   - Или нажмите "🗑️ Очистить всё" для удаления всех файлов

4. **Объедините PDF**
   - Нажмите кнопку "🔗 Объединить PDF файлы"
   - Выберите место и имя для сохранения результата
   - Дождитесь завершения процесса
   - При желании откройте папку с результатом

## Требования

- Python 3.8 или выше
- PyPDF2 3.0.1
- Tkinter (обычно уже включен в Python)

Программа имеет современный и интуитивный интерфейс:

## Решение проблем

### Ошибка: "No module named 'PyPDF2'"

Установите PyPDF2:
```bash
pip install PyPDF2
```

### Ошибка: "No module named 'tkinter'"

На Linux установите tkinter:
```bash
# Ubuntu/Debian
sudo apt-get install python3-tk

# Fedora
sudo dnf install python3-tkinter

# Arch Linux
sudo pacman -S tk
```

### PDF файл не открывается

Убедитесь, что:
- Файл не поврежден
- Файл не защищен паролем
- У вас есть права на чтение файла
